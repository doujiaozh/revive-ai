# revive-ai

> 让 AI 接入每一个操作系统。

## 为什么做这个

现代 AI 工具默认假设你有 Mac / Win11 / 最新手机。
但还有大量设备在运行 WinXP、Win2000、Android 4……
它们不该被 AI 时代抛弃。

这个项目记录：如何在老设备上跑通现代 AI。

## 已复活

| 系统 | 状态 | 方案 |
|---|---|---|
| Windows 7 | ✅ | [win7](./win7) |
| Windows XP | 🚧 | 计划中 |
| Windows 2000 | 🚧 | 计划中 |
| Android 4+ | 🚧 | 计划中 |

## 每个方案的共同点

- 用最少的资源（不依赖 GPU、不依赖新系统）
- 全部开源、可复制
- 记录所有踩过的坑

## 贡献

欢迎 PR：任何"在老设备上跑 AI"的方案。
