# Android (计划中)

目标：让 Android 4.0+ 的老手机跑通现代 AI。

## 计划方案

- **Termux + DeepSeek Harness**：在 Termux 里跑 DSH，浏览器访问 Web UI
- **PRoot Ubuntu 沙箱**：模拟 Linux 环境，跑 Node.js Agent
- **LSPosed 模块**：注入到官方 App（需 Root）
